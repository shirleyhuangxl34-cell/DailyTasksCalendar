WHAT GETS EXTRACTED:
====================

From DOCX document.xml, you'll get:

1. Document Title
   Example: "每日打卡PWA_PRD_V2.0"

2. Sections Identified
   - 产品概述 (Product Overview)
   - 功能需求 (Functional Requirements)
   - 用户故事 (User Stories)
   - 技术要求 (Technical Requirements)
   - 界面设计 (UI Design)
   - 非功能需求 (Non-functional Requirements)

3. Features List
   Example:
   - 员工签到签退打卡
   - 离线打卡支持
   - 实时考勤统计
   - 异常审批流程

4. User Stories
   Format: 作为[角色]，我想[功能]，以便[受益]
   Example:
   - 作为员工，我想快速打卡签到，以便记录工作时间
   - 作为HR，我想查看所有打卡记录，以便统计考勤

TECHNICAL DETAILS:
==================

How It Works:
  1. Opens DOCX as ZIP archive (DOCX = ZIP of XML)
  2. Reads word/document.xml
  3. Extracts text from <w:t> XML tags
  4. Cleans whitespace and artifacts
  5. Parses into sections and structures
  6. Outputs as text and/or JSON

Performance:
  - Small docs (1-10 pages): <100ms
  - Medium docs (10-50 pages): <300ms
  - Large docs (50-200 pages): <1 second
  - Very large (200+ pages): <5 seconds

Memory Usage: 10-50 MB (typical)
