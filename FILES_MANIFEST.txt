HOW TO CONVERT:
1. Open file in Microsoft Word / Google Docs / LibreOffice
2. Save As -> Select "Word Document (.docx)"
3. Use converted file with these scripts

================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "File is not a valid DOCX file"
Solution: Verify file is DOCX format, not corrupted
  - Run: file your_file.docx
  - Or try: unzip -t your_file.docx

Problem: Chinese characters showing as ???
Solution: Set UTF-8 encoding
  - Run: export PYTHONIOENCODING=utf-8
  - Then: python3 parse_prd.py file.docx

Problem: No features or user stories found
Solution: Document may use different formatting
  - Run extract_docx.py first to see raw text
  - Manually review document in Word
  - Check pattern matching in parse_prd.py

Problem: ModuleNotFoundError
Solution: Python version too old
  - Check: python3 --version (need 3.6+)
  - Update Python if needed

Problem: "Could not find document.xml"
Solution: File is not valid DOCX format
  - Not a DOCX file, or corrupted
  - Try opening in Word to repair

For more details, see: DOCX_EXTRACTION_GUIDE.md
